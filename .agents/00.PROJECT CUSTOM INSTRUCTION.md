## 🧠 4. DIAGNOSTIC ENGINE SPECIFICATION (ZOMBIE INDEX™)

### 4.1 ผลลัพธ์ 4 ระดับ (4 Maturity Levels):
1. **ALIVE (31–40 คะแนน)**: องค์กรมีชีวิตชีวา เชื่อมโยง และพร้อมสร้างสรรค์สิ่งใหม่
2. **TIRED (23–30 คะแนน)**: ยังมีพลังและทำงานได้ แต่เริ่มมีสัญญาณความล้าและสะสมพิษ
3. **FADED (15–22 คะแนน)**: พลังและการมีส่วนร่วมลดลงอย่างเห็นได้ชัด คนทำงานแบบหุ่นยนต์
4. **ZOMBIE (0–14 คะแนน)**: องค์กรขาดชีวิตชีวา ไร้การสื่อสารที่แท้จริง อยู่ในภาวะอันตราย

### 4.2 การวัดผลตาม 7 Dimensions หลัก:
1. **Energy** — พลังกาย พลังใจ และความสดชื่นในการทำงาน
2. **Meaning** — ความเข้าใจในเป้าหมายและคุณค่าของสิ่งที่ทำ
3. **Connection** — ความสัมพันธ์ ความไว้ใจ และความผูกพันในทีม
4. **Voice** — ความกล้าเสนอความคิดเห็นและการสื่อสารอย่างเปิดเผย
5. **Psychological Safety** — ความรู้สึกปลอดภัยทางจิตวิทยาเมื่อเกิดข้อผิดพลาด
6. **Ownership** — ความรู้สึกเป็นเจ้าของร่วมและความรับผิดชอบ
7. **Creativity** — พลังในการริเริ่ม ทดลอง และสร้างสรรค์สิ่งใหม่

## 📊 5. CHOOMCHAM HOUSE OS (ADMIN & CRM DASHBOARD)

ระบบหลังบ้านสำหรับผู้ดูแลและทีมงาน Choomcham House เพื่อขับเคลื่อนธุรกิจ Transformation อย่างเป็นระบบ

### 5.1 โครงสร้างหน้า Dashboard (`/admin`)
1. **Executive Overview & Diagnostic Analytics (`/admin/dashboard`)**:
   * Metrics Cards: Total Leads, New This Month, Consultation Rate, Alive/Zombie Distribution.
   * Radar Chart: แสดงจุดแข็ง-จุดอ่อนเฉลี่ยของทุกองค์กรตาม 7 Dimensions.
   * Lead Conversion Velocity Chart.

2. **B2B CRM Pipeline (`/admin/crm`)**:
   * Kanban Board & List View ปรับสถานะลูกค้าได้ 5 ขั้น:
     `New Inquiries` → `Contacted / Qualified` → `Consultation Scheduled` → `Proposal Sent` → `Won / Active Project` (or `Lost`).
   * Detail Drawer: ดูผลคะแนน Quiz ทั้งหมด, คำตอบรายข้อ, Note จากทีมงาน, และปุ่มโทร/ส่งอีเมล.

3. **Project & Transformation Delivery (`/admin/projects`)**:
   * ติดตามโครงการลูกค้าปัจจุบันตาม Process Model: Reset → Reconnect → Recharge → Reimagine → Recreate.
   * เก็บข้อมูล Before / After Metrics เพื่อใช้สร้าง Case Study.

4. **Partner Network & Contribution Ledger (`/admin/partners`)**:
   * บันทึกสัดส่วนการลงแรงและสร้างคุณค่า (Contribution Ledger) 4 ด้าน:
     * **Marketing Contribution** (ผู้สร้าง Lead/คอนเทนต์)
     * **Sales Contribution** (ผู้ปิดการขาย/ประสานงาน)
     * **Solution Contribution** (ผู้ออกแบบ Workshop/เนื้อหา)
     * **Operation Contribution** (ผู้ดำเนินงาน/Facilitator/Logistics)

5. **Pilot 3-Month KPI Tracking (วัดผล 6 ตัวชี้วัดหลัก)**:
   1. *Customer* (จำนวนองค์กรที่เข้าสู่ Funnel)
   2. *Revenue* (ยอดขายโครงการ Transformation)
   3. *Actual Profit* (กำไรสุทธิหลังหักต้นทุนจัดส่ง)
   4. *Marketing / System Cost* (งบประมาณและต้นทุนระบบ)
   5. *Time & Effort* (ชั่วโมงการทำงานของทีมงานและ Facilitator)
   6. *Customer Satisfaction (CSAT / NPS)* (ความพึงพอใจและผลลัพธ์การ Reborn)

## ⚡ 8. DATABASE SCHEMA GUIDELINE (SUPABASE)

```sql
-- 1. Leads & Diagnostic Submissions
create table if not exists leads (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  company text not null,
  position text not null,
  email_or_line text not null,
  team_size text,
  score integer not null,
  result_level text not null, -- 'ALIVE', 'TIRED', 'FADED', 'ZOMBIE'
  answers jsonb not null, -- array of { dimension, score, question_id }
  status text default 'NEW' not null, -- 'NEW', 'CONTACTED', 'CONSULTATION', 'PROPOSAL', 'WON', 'LOST'
  assigned_to uuid references auth.users(id),
  notes text,
  created_at timestamptz default now() not null,
  updated_at timestamptz default now() not null
);

-- 2. Partner & Contribution Ledger
create table if not exists partner_contributions (
  id uuid primary key default gen_random_uuid(),
  partner_name text not null,
  project_id uuid,
  contribution_type text not null, -- 'MARKETING', 'SALES', 'SOLUTION', 'OPERATION'
  percentage numeric(5,2) not null,
  points_or_amount numeric(12,2),
  created_at timestamptz default now() not null
);
```
